# 社長を探せ！ 地球儀版

地球儀のあちこちにいる社長の中から、指名された3人を見つけるまでのタイムを競うスマホ向けブラウザゲームです。

## あそびかた

- 「スタート」を押すと、お題の社長が1人ずつ表示されます。
- 地球儀をなぞって回し、ピンチ（または ＋／− ボタン）でズームします。
- お題の社長をタップすると「発見！」。3人見つけるまでの合計タイムで称号が決まります。
- 違う社長をタップすると +3秒、ヒント（地域名を表示）を使うと +10秒。

## 中身

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム本体（地球儀の描画、配置、ルール） |
| `costumes.js` | 民族衣装の社長、ランドマーク、海の生き物、船・飛行機、気候帯と植物・建物のデータ |
| `chars/` | 社長キャラの画像（切り出し済み）と顔パーツ |
| `data/land-110m.json` | 陸地の形データ（[world-atlas](https://github.com/topojson/world-atlas)） |

外部ライブラリとして [d3](https://d3js.org/) と [topojson-client](https://github.com/topojson/topojson-client) を CDN から読み込んでいます。

## 公開（GitHub Pages）

Settings → Pages → Branch を `main` / `(root)` にして保存すると、
`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。

ローカルで動かすときは、ファイルを直接開くのではなくサーバー経由で開いてください（例：`python -m http.server`）。
