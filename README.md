# 社長を探せ！

指名された社長を3人見つけるまでのタイムを競う、スマホ向けブラウザゲームです。

## モード

- **ノーマル（日本列島）**：47都道府県の社長が、それぞれの県に立っています。お題の社長がどこの県かは、見つけるまで秘密です。持ち物や衣装をヒントに探します。
- **地球儀版**：世界中に散らばった約120人の社長から探します。民族衣装の社長は自国に、それ以外はランダムに配置されます。

## ひみつの社長室

タイトル画面右上の「ひみつの社長部屋」から入れるミニゲーム集です（`office.html`、画像も埋め込み済みの単一ファイル）。

- **ゴミ箱シュート**：社長の席から紙くずをスワイプで投げ、壁際のゴミ箱に入れる。エアコンの風に流される。10球で何個入るかを競う。入らなかった紙くずはその場に残る。
- **椅子スライド**：上から見た社長室で、スワイプするたびに社長の椅子をその向きへひと押し。社長席から①コーヒー→②本棚→③観葉植物→④ドアの順に、マークの上で止まりながらめぐり、⑤社長席に戻ってくるまでのタイムを競う。強くぶつかるとクラッシュして2秒動けない。
- AI秘書：準備中

## あそびかた

- 地図・地球儀をなぞって動かし、ピンチ（または ＋／− ボタン）でズームします。
- お題の社長をタップすると「発見！」。3人見つけるまでの合計タイムで称号が決まります。
- 違う社長をタップすると +3秒、ヒント（地方・地域名を表示）を使うと +1分。

## 中身

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム本体（地図・地球儀の描画、配置、ルール） |
| `costumes.js` | 地球儀版の民族衣装の社長、ランドマーク、海の生き物、船・飛行機、気候帯と植物・建物のデータ |
| `chars/` | 社長キャラの画像（切り出し済み）。`chars/japan/` は47都道府県の社長 |
| `data/land-110m.json` | 世界の陸地の形（[world-atlas](https://github.com/topojson/world-atlas)） |
| `data/japan-pref.json` | 都道府県の形（[jpn-atlas](https://www.npmjs.com/package/jpn-atlas)、国土地理院「地球地図日本」をもとに加工） |

外部ライブラリとして [d3](https://d3js.org/) と [topojson-client](https://github.com/topojson/topojson-client) を CDN から読み込んでいます。
